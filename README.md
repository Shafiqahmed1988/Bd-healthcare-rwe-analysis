# Bangladesh Healthcare — Real-World Evidence (RWE) Analysis

A practice data analytics project exploring disease prevalence, treatment patterns, and healthcare outcomes across Bangladesh, built as part of my transition from pharmaceutical field work into data analytics.

> **Note:** This project uses a **synthetic (self-generated) dataset** modeled on realistic Bangladeshi healthcare patterns. It is **not real patient data** — created purely for learning and portfolio purposes.

## 📌 About

As a Senior Medical Representative in the pharmaceutical industry, I work closely with prescribing patterns, doctor engagement, and market data. This project applies data analytics skills (Python, pandas, matplotlib, seaborn) to a healthcare dataset structured the way real-world evidence (RWE) data typically looks in the pharma industry.

## 🗂️ Project Structure

```
├── Data/          → synthetic dataset (CSV)
├── Scripts/        → Python/Jupyter analysis notebook
├── Outputs/         → generated charts (PNG)
└── README.md
```

## 🔍 Analysis Covered

1. **Disease Prevalence by District** — case distribution across 12 districts, heatmap view
2. **Treatment Pattern per Disease** — which drugs/treatments are most used per diagnosis
3. **Age & Gender-wise Disease Distribution** — demographic breakdown of conditions
4. **Medication Adherence vs Outcome** — relationship between adherence level and patient outcome
5. **Cost Analysis** — average treatment cost by disease and facility type
6. **Monthly Disease Burden Trend** — time trend, including seasonal patterns (e.g. Dengue)

## 🛠️ Tools Used

- Python
- pandas
- matplotlib
- seaborn
- Jupyter Notebook

## ▶️ How to Run

1. Clone this repository
2. Install dependencies:
   ```
   pip install pandas matplotlib seaborn
   ```
3. Open the notebook in `Scripts/` and update the dataset path if needed
4. Run all cells — charts will display inline and save as PNG in the working folder

## 📊 Sample Insights

- Disease burden varies notably by district, with denser urban areas showing higher case volume
- Medication adherence shows a visible link with better patient outcomes
- Treatment cost varies significantly by facility type
